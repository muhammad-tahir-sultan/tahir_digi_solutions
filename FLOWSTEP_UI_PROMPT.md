## DESIGN DIRECTION (WHAT WE WANT)

### Visual Style
- **Premium agency aesthetic** — think Webflow Agency templates, Linear.app polish, or top Tier-1 Webflow/Framer agency sites
- Clean but **rich** — generous whitespace BUT every section has visual depth (not empty)
- **Dark mode primary** OR sophisticated dark-navy + white hybrid (user currently has dark theme)
- Subtle gradients, soft glows, refined shadows — NO heavy glassmorphism everywhere
- **Real photography placeholders** for hero, team, case studies (use Unsplash-style professional business imagery)
- **Custom illustrations** only as accents — not as primary UI filler
- Device mockups should show **realistic full website screenshots** inside frames — not tiny CSS wireframes

### Typography
- Modern sans-serif (Inter, Geist, Plus Jakarta Sans, or similar)
- Clear hierarchy: Display headline → Section title → Body → Caption
- Headlines: bold, confident, not playful

### Color Palette (starting point — refine as needed)
- Primary: Blue `#2563EB` (trust, professional)
- Accent: Cyan/sky `#0EA5E9`
- Background dark: `#0F172A` (slate-900)
- Background light sections: `#F8FAFC`
- Success/growth: Emerald `#10B981`
- Warning/audit issues: Amber `#F59E0B`
- Industry accent colors:
  - Dental: Blue
  - Law: Slate + Gold/Amber
  - Real Estate: Emerald/Teal
  - Accounting: Amber/Orange
  - Physiotherapy: Cyan

### Interaction & Motion
- Scroll-triggered fade-up reveals (subtle, not excessive)
- Card hover: slight lift + shadow increase
- Sticky header with blur backdrop
- Smooth section transitions
- Before/After slider with draggable handle
- Respect reduced motion preferences

### What to AVOID
- Generic Bootstrap/card grid look
- Empty mockups with grey placeholder bars
- Same layout repeated for every industry
- Overlapping mobile mockups that clip content
- Too many floating stat badges cluttering hero
- Comic/emoji-heavy UI
- Cluttered nav with 8+ items feeling cramped
